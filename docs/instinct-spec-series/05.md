Upmore Spec 05: Connector Catalog"What is everything it should be able to connect ranging from bank accounts to portfolios to everything financial related." This is the full list, grouped by domain, each group with its auth method (from doc 04), the data pulled, and the actions enabled. Build order is waves: Wave 1 makes the agent useful, Wave 2 makes it complete, Wave 3 makes it exhaustive.Wave 1: money in, money out (build first)Bank accounts and credit unionsCoverage: thousands of US institutions through one aggregator (Plaid, MX, or Finicity per doc 04). Checking, savings, money market, CDs. Auth: AGGREGATOR. Data: balances, transactions, account numbers (masked), routing. Actions: balance reads, transaction reads, ACH between own accounts where supported (PAY-009, T3). Registry: ACCT family, TXN family, ALRT-001/002/007/008.Credit cardsCoverage: issuer connectors via aggregator plus direct OAuth for the majors (Chase, Amex, Capital One, Citi, Discover, BofA, Wells Fargo, US Bank, Barclays, Synchrony). Auth: AGGREGATOR + OAUTH. Data: balances, APRs, due dates, minimum payments, transactions, rewards balances, offers. Actions: payment initiation where the issuer supports it (CARD-006, T3), offer activation (EARN-010, T3), lock (CARD-011, GATED). Registry: CARD family.Payment appsVenmo, Cash App, PayPal, Zelle (via the user's bank), Apple Cash, Google Pay. Auth: OAUTH where it exists (PayPal), VAULTED_CREDENTIALS or read-only transaction email parsing where it does not (Venmo, Cash App have no official read APIs; Zelle lives inside bank rails). Data: P2P history, balances, linked funding sources. Actions: sends are GATED per doc 06; receipts and IOU matching work from read data alone. Registry: PAY family, SOC family.Payroll and incomeEmployer payroll platforms: ADP, Workday, Gusto, Paychex, Rippling; plus gig income: Uber, DoorDash, Instacart, Lyft, Upwork, Fiverr. Auth: OAUTH or VAULTED_CREDENTIALS; argyle-style payroll aggregators exist and fit the AGGREGATOR method. Data: pay schedule, gross/net, withholding, benefits elections, 401k contributions. Actions: paycheck allocation analysis (ANL-010), bonus tracking (EARN-005), W-4 draft (TAX-008, T2). Registry: ANL-010, TAX family, EARN-005.Email receiptsGmail and Outlook inboxes with finance-scope filters. Auth: OAUTH with narrowly scoped read permission. Data: receipts, order confirmations, subscription renewal notices, bills, flight itineraries. Actions: TXN-015 receipt attachment, BILL-010 trial alerts, BILL-002 price increase detection, EARN-016 delay compensation triggers. Note: this connector also carries prompt-injection risk; treat all email content as untrusted input per SEC-011.Wave 2: assets and debtsBrokerages and investment accountsSchwab, Fidelity, Vanguard, Robinhood, E*TRADE, Interactive Brokers, Webull, M1, Betterment, Wealthfront, Public, SoFi Invest. Auth: AGGREGATOR (Plaid/MX investments coverage) + OAUTH where richer. Data: holdings, cost basis, transactions, dividends, margin. Actions: reads for INV-001 through INV-010; order execution only through a broker-dealer partner rail (doc 09, doc 14), never through scraped sessions. Registry: INV family.Retirement and tax-advantaged401k/403b/457 providers (Fidelity NetBenefits, Empower, Voya, Principal, T. Rowe Price), IRAs at any custodian, HSAs (Fidelity HSA, Lively, HSA Bank), FSAs, 529 plans, ESOP/ESPP administrators (Computershare, E*TRADE Equity Edge). Auth: AGGREGATOR or VAULTED_CREDENTIALS. Data: balances, contribution rates, match terms, vesting, investment elections, contribution room. Actions: contribution tracking (INV-018, TAX-009), match capture check (SAVE-019), ESPP reminders (EARN-006). Registry: INV-018/019, TAX-009, SAVE-019/020, EARN-005/006.Loans and creditStudent loans (MOHELA, Nelnet, Aidvantage, Navient, SoFi), mortgages (servicers: Mr Cooper, Rocket, Wells, Chase), auto loans, personal loans, BNPL plans (Affirm, Klarna, Afterpay, PayPal Pay in 4), HELOCs. Auth: AGGREGATOR where covered, VAULTED_CREDENTIALS for servicers with weak coverage. Data: balances, rates, payment schedules, payoff amounts, escrow. Actions: debt inventory (CRDT-008), payoff plans (CRDT-009/010), refinance watch (CRDT-011), BNPL stacking warnings. Registry: CRDT family, HOUS-004/005.Credit bureaus and scoresExperian, Equifax, TransUnion; score surfaces via Credit Karma, issuer FICO scores already pulled in the card connectors. Auth: OAUTH or VAULTED_CREDENTIALS. Data: scores, report line items, inquiries, freeze status. Actions: CRDT-001 through CRDT-007, SEC-006. Registry: CRDT family.CryptoExchanges: Coinbase, Kraken, Gemini, Binance.US. Wallets: read-only via public address watching for BTC/ETH/SOL. Auth: OAUTH (exchanges), MANUAL/public-key watch (wallets). Data: balances, transactions, cost basis where available. Actions: INV-001 consolidation, TAX-007 export, INV-022/023 analogues. Registry: INV family, TAX-007.Wave 3: the long tail that makes it exhaustiveBills and utilitiesElectric, gas, water, internet, mobile carriers (Verizon, AT&T, T-Mobile), streaming and software subscriptions (detected via transactions, confirmed via provider logins where useful), gym memberships, storage, parking. Auth: VAULTED_CREDENTIALS mostly; some via bill-pay eBill surfaces. Data: bill amounts, due dates, plan details, usage. Actions: BILL family, SAVE-009 plan optimization, BILL-005 negotiation prep. Registry: BILL, SAVE-009.InsuranceHealth (including insurer portals and HRA administrators), auto, home/renters, life, disability, pet, umbrella, travel. Auth: VAULTED_CREDENTIALS; OAUTH rare. Data: policies, premiums, coverage terms, deductibles, claims status, beneficiaries. Actions: INS family, SAVE-008 rebids. Registry: INS.Housing and propertyMortgage servicers (above), property tax via county records (public data), HOA portals, landlord/rent portals (AppFolio, Buildium, RentCafe), rent reporting services (Esusu, LevelCredit, Bilt), Zillow/Redfin estimates (public data with clear accuracy labels). Auth: VAULTED_CREDENTIALS + MANUAL + public data. Data: rent terms, lease dates, assessments, estimates. Actions: HOUS family, PAY-005 rent execution per doc 06. Registry: HOUS.Government and public moneyIRS account transcripts (id.me OAuth), state tax portals, Social Security (ssa.gov), state unclaimed property databases (public search), USAspending for grants, studentaid.gov. Auth: OAUTH (id.me ecosystem) + public data. Data: transcripts, refund status, benefits statements, unclaimed property hits. Actions: TAX-012, EARN-007, TAX-010. Registry: TAX, EARN-007.Rewards and loyaltyAirlines (United, Delta, American, Southwest), hotels (Marriott, Hilton, Hyatt, IHG), card portals (Chase UR, Amex MR, Citi TYP, Capital One miles), retail (Amazon, Target, Walmart, Walgreens, CVS), dining programs. Auth: VAULTED_CREDENTIALS + aggregator where supported. Data: point balances, expiry dates, transfer partners, tier status. Actions: EARN-011/012, SAVE-013. Registry: EARN-011/012.Shopping and receiptsAmazon order history, Walmart, Target, Costco; price-tracking surfaces. Auth: VAULTED_CREDENTIALS + email receipts. Data: orders, prices paid, return windows, warranties. Actions: SAVE-011/014, EARN-014/015, TXN-015/016. Registry: SAVE, EARN, TXN.Business money (if the user has any)QuickBooks, Xero, Wave; Stripe, Square, Shopify payouts; business bank accounts; business credit cards. Auth: OAUTH + AGGREGATOR. Data: revenue, expenses, invoices, payout schedules. Actions: separation of business and personal analytics, quarterly estimated tax inputs (TAX-003), invoice status. Registry: ANL, TAX-003/006.Manual and offlineCash spending log, physical assets (vehicle values via KBB public data, collectibles via manual entry), debts owed to the user by people, paper statements scanned. Auth: MANUAL. Data: whatever the user enters, with source labeled manual. Actions: TXN-014, PAY-017, net worth completeness. Registry: ACCT-007, TXN-014, PAY-017.The catalog table formatEvery connector ships as a row in src/connectors/catalog.ts: provider id, display name, domain, auth method, wave, scopes, data entities, registry capabilities powered, write actions, reliability class, and the GATED reason where applies. The "what can you connect" answer (CORE-002) is generated from this table, so it is always complete and never aspirational.Build packet for Claude CodeContext: build the catalog table and adapters in waves. Wave 1 first: aggregator adapter for banks/cards, PayPal OAuth, email receipt connector, payroll read adapter. Each adapter follows doc 04's five verbs and the reference adapters.Constraints: every catalog row names its auth method and reliability class honestly; no row ships with actions the adapter cannot perform. Email content is untrusted input.Done when: pnpm vitest run src/connectors/catalog validates every row (valid auth method, capabilities exist in the registry, GATED rows have reasons). pnpm connectors --list prints the catalog grouped by wave. Each Wave 1 adapter passes its fixture tests.How Claude Code proves it is betterCoverage test: take 25 real user financial life scenarios ("I get paid by Gusto, rent through RentCafe, carry a Chase card, hold a 401k at Empower, have Affirm plans, get money back on Freecash") and assert the catalog answers "yes, via this connector, this auth method" for every surface named, with zero honest gaps unlabeled. Freshness test: the catalog carries a last-checked date per provider auth method; a scheduled eval re-verifies a sample of providers monthly (OAuth URLs resolve, aggregator coverage lists still include the institution) and files a registry diff when reality moves.Previous: Connector ArchitectureNext: Money MovementDraft specification.
