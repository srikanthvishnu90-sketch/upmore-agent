Source tests pin validated addresses, reject mixed private/mapped DNS answers and refuse every redirect before any second request. These are injected network tests, not observed public requests.
2. **Stale and future observations were accepted.** The worker now requires capture/navigation timestamps within the admitted read window, with 30 seconds clock tolerance. Five-minute stale/future fixtures are refused. Persisted status binds archived capture time to the original effect admission; it does not falsely make an old archive current merely because it is polled.
3. **A PNG signature was treated as a screenshot.** Research-only validation checks bounded RGB/RGBA PNG chunks, CRCs, header, terminal chunk, decompression and scanline framing. A valid synthetic one-pixel protocol fixture exercises acceptance; signature-only bytes are rejected. This establishes image-format validation, not that pixels came from a browser. Format reference: [W3C PNG specification](https://www.w3.org/TR/png-3/).
4. **Chat status trusted mutable persisted evidence.** A changed artifact hash, task/intent/source binding or provenance was returned as source evidence. The source-only SQL proposal now returns owner-scoped immutable intent and completed-read receipt metadata beside the task. Edge validates canonical artifact/capture hashes, immutable goal/URL/turn/thread/request bindings, source/capture consistency and screenshot bounds before quoting source text. Recomputed forged artifact hashes still fail the independent request/effect checks. The research effect uses canonical sorted-JSON capture hashing; application effect hashing and approval payload forwarding are preserved. This is not tamper-proof against an administrator rewriting both authoritative tables and results.
5. **Unconfirmed central publication stranded captured evidence.** The worker previously returned early whenever local result existed, leaving the SQL intent claimed after a failed save.
