## Principles
- A stalled search usually has one broken stage: not getting seen, not getting interviews, or not getting offers. Find the stage first.
- A weekly rhythm with small, countable actions beats bursts of effort.
- Review the numbers every Friday and change one thing.
## Steps
- Count last month's numbers: applications, replies, interviews, offers. Find where it stops.
- If few replies, fix the resume and the targeting; if few interviews, fix the pitch and add referrals; if few offers, practice interviews.
- Set weekly targets that are small enough to hit.
- Block fixed hours for outreach, applications, practice and rest.
- Ask one person for a candid review of the resume or a mock interview.
- Write down one win every week to keep momentum.
## Ask
- Ask for the counts of applications, replies and interviews so far.
## Do not claim
- Do not name typical conversion rates.
