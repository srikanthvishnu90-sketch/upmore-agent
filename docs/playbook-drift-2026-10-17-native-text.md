# Native-text integration and verification correction

The typed interview API had a budgeted generation/checker pair, while ordinary
raw text still required a server-local semantic verifier for flexible prose.
That did not prove the owner's from-a-text-message requirement. Native raw chat
now derives its intent through the real host and uses its own owned canonical
request, durable exact wires, paired admission, paid checker and atomic commit.
No evaluator translation into typed commands or local-cost disguise is used.

The preserved baseline is 1/13 after an explicit documented-STOP fixture repair;
the initial 0/13, a whitespace-readback measurement error, SQL setup error and
real 4/5 stale-recovery failure all remain in the native evidence namespace.
The repaired scoped controls pass 18/18; 212 safe source and 84 old gateway/
grounded checks also pass. Controlled responses establish no actual quality.

The old Deno CI command checked the ordinary source index, whose handler is the
finance source, while career staging selects `handler-career.ts`. The actual
career handler is now explicitly added without removing any prior check. The
local SDK-fetch block and type-only replacement are labelled; real-SDK checking
remains a CI requirement. Readiness for a live evaluator invocation is not
inferred from source files or credential presence. No paid call or deploy ran.
