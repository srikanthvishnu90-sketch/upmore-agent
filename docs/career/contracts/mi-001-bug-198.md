## Defect statement

The architecture supplies the turn clock as **numeric epoch milliseconds** — the gauntlet
harness pins it (`pilot-lib.cjs`: `STAGING_NOW = Date.parse("2026-10-13T12:00:00Z")`, a number)
and the production host passes a number too (`career_host.js`: `now: typeof o.now === "number"
? o.now : Date.now()`). Six call sites nevertheless feed that value to `Date.parse()`, which
returns **NaN for a numeric argument** (verified: `Date.parse(1760361600000) === NaN`). Each
site then silently falls back to the real wall clock, throws, or computes NaN verdicts:

| # | Site | Proven effect (fail-first, 2026-10-15) |
|---|---|---|
| 1 | `141-career-doorstep.js` `emitCalendarProposal` (l.1253) | SC-143's slot verdicts flip with the wall clock: the BUG-198 guard PASSES at a faked 12:00Z wall clock and FAILS at a faked 21:35Z wall clock ("a past slot is still being offered") on the identical build |
| 2 | `128-career-negotiation.js` `deadlinePlan` (l.238) | **throws** `RangeError: Invalid time value` on a numeric `opts.now` |
| 3 | `129-career-os.js` `networkUpkeep` (l.115) | **throws** `RangeError: Invalid time value` on a numeric `opts.now` |
| 4 | `145-career-w11-ext.js` `pressurePlan` (l.265) | `hours_left_at_plan` = NaN on a numeric `opts.now` |
| 5 | `135-career-graph.js` `keepWarm` (l.194) | silently returns no due entries, ever, on a numeric `opts.now` (every `days >= threshold` comparison against NaN is false) |
| 6 | `142-career-router.js` (l.1093) | passes `Date.parse(ctx.now)` = NaN as `nowMs` into 124's `draftAndGate`; NaN is falsy there, so the stale-record check is silently skipped and recency scoring runs on the wall clock |

Split note (master-list rule): sites 2–3 sit in modules whose *capability* builds are Crew B's
(MI-014/MI-015); the change there is this defect repair only — a type-safe clock coercion,
identical in shape at every site, no behavior redesign.
