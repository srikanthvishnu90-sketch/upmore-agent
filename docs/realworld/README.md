## What the words mean

- **Logic**: LOGIC_PROVEN = a registry id behind the item went through the depth protocol (15 sub-capabilities, each proven to fail under its planted defect). LOGIC_TESTED = every registry id behind it is TESTED (its test exists and passes). PARTLY_TESTED = some are. DESIGNED = none is; the connector path, the completion proof, the gate and the failure message are written, the pure logic is not.
- **Rail**: LIVE = an adapter in the catalog is live. SANDBOX = a faithful local counterparty proves the outcome (today only subscription cancellation, in a real Chromium against a merchant that keeps state). NOT_WIRED = no adapter can reach the counterparty; the engine says so instead of pretending.
- **Done** is the top line and nothing else: a live run against the real counterparty, recorded under docs/realworld/evidence/, whose read-back passes the item's proof check. LIVE rail alone is not done; SANDBOX is never done; LOGIC_PROVEN is never done.
