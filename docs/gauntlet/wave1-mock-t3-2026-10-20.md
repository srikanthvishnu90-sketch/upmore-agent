## 1. The mechanism (what was actually broken)

The prep capability (127's question banks, mock rounds, `mockSummary`) was
intact. Four linked breaks in `packages/domain/142-career-router.js` kept
genuine-English mock turns from ever reaching it or holding a session —
reproduced by replaying all 40 class-"mock" battery scenarios (84 turns,
`channel-tests/2026-10-20-live-battery/results.jsonl`) through the real
CareerHost on base code; on the composed tree the same replay has **0 fallback
turns**:

1. **Mock start refused profile-less users, stranding every later turn.** The
   mock-start dispatch gate returned a `prep_needs_profile` stub when
   `profile` was null — reading the STALE `profile` const captured at dispatch
   top, before the stated-facts bridge installs `c.profile`. A user whose
   record is stated facts (no full profile) was refused; no session ever
   existed, so their answers, advances and debriefs fell to the generic
   fallback ("I didn't catch that…") turn after turn. `handlePrepStart` also
   took its subject only from `ctx.posting` — the role/company named in the
   ask itself ("for a Backend Engineer, New Grad role at Fieldnote Software
   (fictional)") was never parsed, and 127's bank is keyed by sector, so a
   bare engineering title needs a roleFamily translation.
2. **Labelled answers were released as new tasks.** The pending-mock capture's
   label-led release shape (`/^[A-Za-z][^:]{1,48}:\s/`) read "My answer: …"
   (CB-0355/0356 turn 2) as a task label and released it to fallback.
3. **Debrief asks were owned by nobody.** "how did I do? score me honestly"
   is question-shaped → released by the capture, matched no route → fallback,
   though 127's `mockSummary` over the recorded answers existed.
4. **The question-bank ask in natural words never reached the bank.** "what
   questions does Fieldnote Software (fictional) ask for Backend Engineer,
   New Grad roles?" contains neither the literal "question bank" (the only
   key `handlePrepExtras`' bank branch had) nor any session shape. The
   mechanism distinguisher is **direction**: questions a company asks the
   candidate vs questions the candidate should ask them (the
   questions-to-ask producer keeps its own shapes).

## 2. The fix (142 only, plus regenerated bundles)

- **Mock start:** the dispatch gate's profile refusal is removed — the start
  always reaches `handlePrepStart`; session state lives on the prep-thread
  record and survives the turn boundary with or without a profile.
  `handlePrepStart` parses the named role/company from the ask (frames:
  `for a/an <Role> role at <Co>`, a mock-scoped `mock … for <Co>` fallback,
  else `companyFromText`), translates the title to a roleFamily
  (finance/product/data/swe), and builds the bank with `{company, role,
  roleFamily}`. The grounding line is honest: profile grounding is claimed
  only when a profile exists; otherwise the mock runs from the researched
  question bank and says nothing about the user's history is assumed.
  Two null-profile dereferences on this path (`detectContradiction`, the
  prep-retry story lookup) are guarded.
- **Capture:** an explicit answer label (`my answer:` / `answer:` /
  `my response:` / `here's my answer:`) is session content — exempt from the
  task-shaped release.
- **Debrief:** new `handleMockDebrief`, claimed inside the standing session
  alongside the advance claim. Shapes: how-did-I-do / score me / grade me|my /
  score my answer|mock / debrief / give me feedback / what's my score / my
  verdict. Zero recorded answers → an honest "nothing to score yet", session
  stays open. Otherwise it serves `Prep.mockSummary` (answered count of total,
  rubric averages for structure/evidence/specificity, weakest area, first
  what-didn't-land question) and closes the session (profile + prepThread
  prepMock cleared), intent `prep_mock_debrief`.
- **Question bank:** `qbAsk` in `handlePrepExtras` = the literal shape OR
  (`what|which questions` + ask-form), with stand-downs (`should i ask`,
  `i should ask`, `to ask`, `ask them|the panel|the interviewer|him|her`) so
  the questions-to-ask producer keeps its turns; the extras dispatch gate is
  widened to admit the natural shape. `bankArgs` extracts the named role
  (`ask for <Role> roles`) into 127's `role` and widens the swe roleFamily
  pattern (engineers/backend/developer). Role-first row ordering applies only
  to the natural shape; the literal shape keeps its legacy order.
- **Matcher:** the mock-start pattern admits verb forms (`practice
  interviewing`) — caught by this lane's own paraphrase guard (W1-5 routed to
  company_intel on the first pass).
- **Deliberate non-change:** an initial role-row reordering inside
  `handlePrepStart` flipped the existing pin `career-lane-a-depth` CB-0321
  (its advance assertion expects a behavioral opener); the reordering was
  removed from the start path and the pin passes again. The natural-bank
  role-first ordering is scoped to `handlePrepExtras` only.

No battery literal was bolted on as a pattern (BUG-213 guard standard); every
new shape is a mechanism (session state, answer label, ask direction, named
role/company frames) proven on fresh paraphrases at invented firms.
