## Switched off until the owner decides

- **Prediction market** (Kalshi, Polymarket, PredictIt, Robinhood Event Contracts, ForecastEx (Interactive Brokers)): the gambling guard stays on until the owner decides (Decision 2). If he ever lifts it, Upmore states numbers only (prices, implied odds, fees, P&L) and never encourages or suggests a position.
- **Crypto** (Coinbase, Kraken, Gemini, Binance.US, Crypto.com, Bitstamp, Robinhood Crypto, eToro (crypto + stocks), bitFlyer, Uphold): Upmore's shipped hard rule is no crypto (the chat's crypto guard), so this stays off until the owner lifts that rule in writing.
- Prediction markets, standing rule (owner, 2026-10-11): Upmore never encourages a Kalshi or Polymarket decision. If they
  are ever switched on, anything Upmore says or does there rests on numbers only (prices, implied odds, fees, the
  person's P&L), never a nudge toward a position.
