PROMPT FOR CLAUDE CODE: WIRE THE UPMORE CONVERSATION CORPUS

Context: upmore-agent has five files, upmore-convo-corpus-1-of-5.txt to 5-of-5.txt, canonical examples of how the assistant responds. Put them in /corpus/ in the repo. Do not edit the mannerisms; extend them.

1. Few-shot style layer
- Parse each "### n.nn Title" block into {id, tags, turns, note}.
- Build a selector: embed the incoming user message, retrieve the 6 nearest examples (always include the safety examples 2.08, 2.09, 5.01, 5.04), and insert them in the system prompt under "STYLE EXAMPLES: copy the mannerisms, not the words".
- Hard rules above examples: never invent balances or prices; every money move needs a confirmation card; a yes covers only the latest card; never retry a money move when state is unknown.
- Placeholders like [price from tool] must always come from a tool result at runtime.

2. Eval references
- For each example, make a test: feed the user turns, check the assistant turn. Grade by rules, not string match: exact amounts and handles present, card present before money move, no fake success, under 3 sentences unless a card, correct refusal.
- Add an LLM judge scoring mannerism match 1-5 against the nearest corpus examples; fail under 4.
- Generate variants (typos, slang, look-alike names, stale and double yeses) from each seed.
- Run on every commit. Report pass rate by file.

3. Weekly growth
- Every Sunday, export real conversations that were (a) failures, (b) corrected by the user, (c) new situation types. Redact names, handles, numbers.
- Rewrite the assistant side into the corpus mannerisms, tag, append to file 5 or a new corpus-N file, review by hand, merge.
- Each failure becomes a permanent eval.

4. Done when: selector wired, evals running, first weekly export script committed, and a report of eval pass rates posted.
