# Question map: real application questions read by meaning (WO-020)

Generated by `deno run --allow-read --allow-write evals/apply/question-map.ts --write docs/apply/question-map.md`.

## Against independent hand labels (240 random required questions)

- Precision: 97.5% (of 236 questions the map placed). Recall: 97.5%.
- Fill precision: 99.5% of 189 questions it would fill from the person's facts with no one looking first (fact, derived, file). Every other kind is shown in the approval.
- In-sample: the map's rules were written after reading the unknown questions of both captured samples, which the labeled sample is drawn from. A held-out capture is the next measure.

Left to ask means unknown: the map could not place it. Screens, attestations, consents and essays are not filled from defaults: they are shown in the approval (an essay drafted only from confirmed facts), so nothing about them is asked in a later text.
